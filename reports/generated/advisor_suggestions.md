# AdaRankLab Pro 微调策略推荐报告

本报告依据已有训练结果、AdaRank Score、Rank 诊断、重要性评分和预算调度实验，为不同应用场景给出推荐策略。

## 1. 总体推荐结论

- **最高 SST-2 性能优先**：推荐 `sst2_lora_r16_e3`，Accuracy=0.907110，F1=0.909295，可训练参数=591362。
- **综合效率优先**：推荐 `sst2_lora_r2_e3`，AdaRank Score=64.5042。
- **参数最省且性能可接受**：推荐 `sst2_lora_r2_e3`，可训练参数=75266，Accuracy=0.873853，F1=0.879121。
- **AdaLoRA 预算调度优先**：推荐 `slow` 策略，Accuracy=0.878440，F1=0.883516。

## 2. 面向不同需求的推荐

### 2.1 追求最高分类性能

推荐使用 `sst2_lora_r16_e3`。该实验在 SST-2 上取得当前最高综合性能，Accuracy=0.907110，F1=0.909295。
适用场景：最终模型精度优先，对训练参数量要求不极端严格。

### 2.2 追求参数效率和训练效率

推荐使用 `sst2_lora_r2_e3`。该实验在 AdaRank Score 中排名最高，说明其在性能、参数量和训练成本之间具有较优折中。
适用场景：课程演示、资源受限设备、小规模快速实验。

### 2.3 追求动态秩压缩和可解释性

推荐使用 `sst2_adalora_strict_rank` 或 `sst2_adalora_importance`。严格 AdaLoRA 实验最终剪枝比例为 44.44%，effective rank 范围为 3 到 10，query 平均 rank=5.75，value 平均 rank=7.58。
适用场景：需要展示 AdaLoRA 动态秩分配、剪枝过程、模块重要性差异的研究型实验。

### 2.4 只允许开放部分模块时

模块消融实验中，最佳方案为 `sst2_full_lora_r4_e3`，Accuracy=0.894495，F1=0.898455。
其中 FFN-only 的 Accuracy=0.892202、F1=0.897603，Attention-only 的 Accuracy=0.885321、F1=0.889381。
因此，在当前 SST-2 设置下，如果只能选择一类模块，优先推荐开放 FFN 模块。

### 2.5 采用 AdaLoRA 时如何选择预算调度

预算调度对比显示，`slow` 策略取得最佳结果，Accuracy=0.878440，F1=0.883516。
因此，建议不要过早完成预算收缩，而应保留较长预算调度阶段，让模型更充分地估计参数重要性。

## 3. 机制解释建议

重要性评分实验显示，query 平均重要性为 1.080656e-06，value 平均重要性为 2.395986e-03。
重要性评分与最终 effective rank 的相关系数为 0.4642，说明重要性更高的模块更倾向于保留较高 rank。
Top 重要模块主要集中在 value 子模块，因此报告中应强调 value 在当前任务中的重要性。

## 4. 不推荐直接采用的方案

- 不建议将初版 `train03.py` 的 Rank 记录作为最终证据，因为该版本中 effective_rank 未出现有效分化。
- 不建议只依据单一 Accuracy 判断方法优劣，应结合参数效率、训练效率、rank 压缩和可解释性综合评价。
- 不建议将普通 AdaLoRA r2/r4 的短训练结果作为最终结论，因为其动态秩调度尚未充分发挥。
